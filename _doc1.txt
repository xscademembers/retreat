9. Technical Stack & Build Approach
<tech_stack>
9.1 Stack decision
Default to a static, statically-rendered build. Reasons: fastest LCP, lowest INP, no hydration cost, easiest to host anywhere, easiest to debug. Acceptable approaches in order of preference:
Plain HTML + vanilla CSS + minimal vanilla JS (preferred). Tailwind CSS used in build mode (compiled to a single CSS file ≤ 30KB), NOT via CDN.
Astro (static output). One .astro page, components for each section.
Next.js with output: 'export' (static export). Acceptable but heavier.
Do NOT default to a SPA framework with client-side routing. The current site is a Vite/React SPA and that is part of the LPE problem.

9.3 Image rules
Serve AVIF first, WebP second, JPG fallback via <picture> element.
Hero image: <link rel="preload" as="image" type="image/avif"> in <head>.
Specify width and height on every <img> to prevent CLS.
Below-the-fold images: loading="lazy" decoding="async".
Use srcset and sizes for art-direction across breakpoints.
9.4 Fonts
Self-host woff2 only. Use Plus Jakarta Sans (already on the brand), Inter, or Manrope.
Subset to Latin only. Two weights maximum (e.g., 400 + 700).
font-display: swap. Preload the body font.
9.5 JavaScript discipline
No jQuery. No Bootstrap. No carousel libraries. The image gallery should be a CSS scroll-snap carousel, not a JS lib.
All non-critical JS deferred (defer attribute or type="module").
FAQ accordion should use <details> + <summary> — no JS needed.
Sticky mobile call-bar can be pure CSS (position: sticky / fixed).
9.6 Hosting / deployment
Recommend Cloudflare Pages, Netlify, or Vercel for static deploys with global edge caching.
If keeping the Wix domain, host the new page on a subdomain (e.g., book.salsonsretreat.com) and point Google Ads there.
Set Cache-Control: public, max-age=31536000, immutable on hashed assets.
</tech_stack>

13. Constraints — Things You Must NOT Do
<constraints>
Do NOT use stock photos. Real property photos only.
Do NOT invent guest reviews or testimonials. Use only real Google reviews; if unavailable, leave the section as a TODO with placeholders.
Do NOT claim amenities the property doesn't have. If pet policy / alcohol / A/C rooms are unconfirmed, mark with {{}} placeholder and list in CONTENT_NEEDED.md.

Do NOT load Tailwind via CDN. Compile it to a single static CSS file.
Do NOT use a JS-heavy carousel. Use <picture> for art direction and CSS scroll-snap for the gallery.
Do NOT build as a SPA. The current React SPA is part of the LPE problem.
Do NOT add icon fonts (FontAwesome, Material Symbols full library). Inline only the SVG icons you actually use.
Do NOT add chat widgets (Tawk, Drift, etc.) on launch. They tank LCP and the audience prefers calling.
Do NOT under any circumstance ship without testing on a real Indian-network throttled mobile device profile.
